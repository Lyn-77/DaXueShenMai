# 数学可靠性、工具与冲突处理

在计算复杂、定理条件容易遗漏、需要本地工具复核、答案来源冲突或无法确认结论时读取。

## 证据层级

每个数学结论至少由以下一种证据支撑：

| 证据 | 合法用途 |
|---|---|
| 题干明示条件 | 当前题直接前提 |
| 定义与定理 | 条件满足后的逻辑推导 |
| 代数推演 | 等价变形或单向蕴含 |
| 反例 | 否定全称命题或说明不能推出 |
| 本地工具复核 | 检查复杂算术、符号运算、矩阵或图形 |
| 官方考纲 | 判断能力边界 |

不要把模型记忆、答案册、培训机构材料或工具原始输出当作无需审查的证明。

## 条件检查

优先显式检查会改变结论或方法合法性的条件：

- 洛必达法的未定式类型及邻域可导性；
- 中值定理的闭区间连续、开区间可导；
- 约分、平方、开方、取倒数和变量代换的等价性；
- 矩阵可逆性、秩、特征向量数量与参数临界值；
- 概率独立性、密度归一性、矩是否存在；
- 级数判别和逐项运算的收敛前提；
- 积分区域边界、方向与奇点；
- 端点、定义域、参数分支和量词。

题干中明显满足且不影响判断的常规条件可以只做内部检查；若用户错误正来自该条件，纠错时必须写出。

## 何时使用本地工具

工具可用且出现以下任一情况时做独立复核：

- 多次高风险展开、约分或分式合并；
- 高阶导数、复杂积分、级数系数或多参数分支；
- 三阶及以上行列式、特征值、矩阵幂或长秩计算；
- 多重概率积分、复杂期望或方差；
- 小数近似、精度判断；
- 可以通过代入、求导、矩阵乘法或符号化简独立检查；
- 对无辅助计算结果存在实质疑问。

简单心算、直接公式代入和显然恒等变形不必调用工具。

优先选择不同于原推导的检查：

- 极限：另一种展开、符号极限或数值抽样；
- 导数：重新求导或回到定义；
- 积分：对原函数求导或数值抽查；
- 方程：代回原式并检查增根；
- 矩阵：乘法、秩、行列式、迹或特征关系；
- 概率：总概率、边缘分布和数字特征恒等式；
- 证明：逐个检查蕴含方向并尝试反例。

## 采信工具前

依次核对：

1. 输入表达式是否与题干完全一致；
2. 变量、定义域和参数假设是否一致；
3. 代码或命令是否实现预期运算；
4. 结果是精确值还是浮点近似；
5. 精度是否足以区分候选结论；
6. 工具是否省略或附带条件分支。

检查通过后，工具在复杂算术和符号运算上优先于无辅助心算，但不替代面向用户的数学推导。

只向用户呈现：

### 验证结果

**验证方法：** 代入、求导回代、符号化简、数值抽样、矩阵运算等。

**验证结论：** 与推导一致、不一致，或仍无法确认。

默认不展示代码和原始输出。

## 浮点陷阱

- 接近零不等于精确为零，例如浮点计算中的正弦函数在圆周率处可能返回极小非零值；
- 数值抽样只能发现问题或提供旁证，不能独立证明一般命题；
- 临界参数、重根、病态矩阵和相消问题优先使用精确运算；
- 小数结论要说明精度或误差范围。

## 冲突回退协议

推导与工具、答案册或另一方法不一致时：

1. 冻结候选答案，不进入“最终答案”；
2. 检查题干识别、题号和答案定位是否对应；
3. 检查工具输入、变量假设、实现和精度；
4. 找到双方最后一致的中间状态；
5. 从该状态分别重算，定位首次分歧；
6. 修复推导或工具实现；
7. 使用独立方法再次验证；
8. 只有结果一致或已有严格证明时才输出最终答案。

仍无法解决时明确说明“无法可靠确认”，并具体指出尚未确认的环节。禁止隐藏冲突或任选一个结果。

## 答案册

- 答案册只用于发现冲突和验收参考；
- 不能因为答案册给出某结果就跳过独立推导；
- 不一致时检查 OCR、年份、卷别、题号和答案页定位；
- 至少使用一种独立数学检查，复杂计算优先再用工具；
- 确认答案册错误时只在测试记录中标注，不修改源文件。

## 工具不可用

- 不自动安装 Python 包、SymPy、Matplotlib 或其他工具；
- 继续给出严格人工推导；
- 对按复杂度本应代码复核的计算，披露“未进行代码复核”；
- 绘图工具缺失时改用精确文字或标注“示意”的 ASCII 图；
- 不因缺少可选工具而拒绝普通解题。
