- 确认歧义输入处理：截图模糊、题干残缺或符号有歧义时，先展示推测出的候选题干，让用户选择，或要求用户手动输入、补充描述；不得擅自选定后继续解题。
- 确认题干呈现：输入清晰时也要在讲解开头完整复述并规范化呈现题目，供用户核对识别结果。
- 确认输出密度：采用自适应结构，省略对当前题目没有教学价值的固定栏目；若用户仍不理解基础步骤，由用户主动追问，不要求 Skill 预先覆盖所有理解层级。
- 确认命名方向：三个 Skill 使用 `dxsm-` 品牌前缀，含义为“大雪深埋”，致敬“软微圣经”。
- 确认数学 Skill 正式名称：`dxsm-math`。
- 确认仓库结构：一个仓库内维护 `dxsm-math`、`dxsm-english`、`dxsm-408` 三个相互独立、分别触发的 Skill。
- 确认触发边界：题目截图、自然语言题干、LaTeX 公式加题干描述均触发；只问定义或定理结论不触发；询问定理如何推出、为什么成立或为什么这样计算时触发。
- 确认教学目标与深度：以让用户真正理解为核心，默认包含直觉解释、方法或构造的来源、严格推导以及条件的作用；不局限于应试步骤，也不默认扩展到超出考研范围的历史与高级推广。
- 确认多解法策略：存在多种可行解法时，默认完整展示两种方法；最后站在答题者角度选择更合适的方法，并根据步骤长度、适用条件、计算风险、考场效率等因素说明理由。
- 确认多解法例外：只有一种自然、可靠且有教学价值的解法时，只输出该方法；不得为了凑数量而加入冗长、偏门或莫名其妙的解法。
- 确认判题与纠错职责：用户要求检查自己的解题过程时，若未提供过程，先要求补充其已完成步骤；收到后沿用户原思路判断，从首次错误或卡点继续完成题目，明确指出错误位置，并总结下次遇到同类错误或卡点时可自行采用的推理方法。
- 确认纠错中的方法切换：用户原方法明显低效或根本不满足适用条件时，切换到更合适的方法；切换前说明原方法的问题、停止继续的原因以及新方法的优势。
- 确认判题边界：只判断用户步骤和最终结果是否正确，不估算分数，也不猜测阅卷得分点。
- 确认可靠性原则：所有判断与结论都必须有题干、定理条件、推导或验证依据；信息不足时追问，无法可靠确认时明确说明不确定，不触碰容易导致无依据生成的内容。
- 确认计算验证流程：复杂计算在工具可用时使用 Python 等代码工具独立复核，并在解答末尾追加“验证结果”；若推导与工具结果不一致，先定位冲突来源，确认推导出错时回退到首次错误处重新推演，禁止忽略矛盾直接输出。
- 确认计算可信度规则：先核对工具输入与题干、变量假设、代码实现及数值精度；检查通过后，工具结果在复杂算术和符号运算上优先于模型的无辅助计算。出现冲突时同时审查代码与推导，不机械服从任意一方。
- 确认选择题分析规则：逐项分析所有选项；若多个错误选项使用同一种干扰机制，只完整分析其中一个，其余选项标明与哪个选项同类，避免重复讲解。
- 确认输出版本：只提供完整的理解型讲解，不在末尾重复附加去掉教学旁白的考场精简作答版；最终答案仍需明确标出。
- 确认越界处理：明显超出考研数学内容的题目不处理，只向用户明确说明 `dxsm-math` 的能力边界。
- 确认大纲版本管理：以教育部、教育部教育考试院、中国教育考试网及高等教育出版社可核验的官方信息为准；采用最新官方已验证大纲。新版正文暂时无法可靠取得时，沿用上一份已验证版本并明确标注知识截止年份，不根据培训机构或自媒体转载自行推断更新。
- 确认题型定位格式：每道题先按“学科模块 → 章节 → 题型 → 可用方法”给出分层定位，说明它在考研数学知识体系中的位置。
- 确认关键线索格式：用“题干原文或公式 → 数学含义 → 对解法的影响”的映射呈现关键线索，使方法选择能够追溯到具体题干依据。
- 确认逐步推导排版：使用编号小标题和普通正文，按“当前式 → 为什么这样做 → 使用公式或定理 → 代入与化简 → 当前结论”组织关键步骤；说明文字左对齐，关键式子使用独立展示公式并居中，不使用引用块包裹主推导。
- 确认输出语言：跟随题目语言；中文题使用中文讲解，英文题使用英文讲解，并保留原题的数学符号体系。
- 确认无语言线索时的默认语言：用户只发送 LaTeX 公式或纯公式截图时，默认使用中文讲解。
- 确认题目完整性处理：截图、符号或语句残缺导致题意无法唯一识别时，向用户追问并要求补充；题目语义完整但条件不足以推出目标结论时，直接分析充分性，并用推导或反例说明“不能推出”，不擅自补条件。
- 确认图示规则：只在图形能显著提升理解时使用；优先用 Python 生成可验证的静态图，三维问题按需增加投影或截面；绘图工具不可用时退化为精确文字描述或简单 ASCII 图。生成式图片不用于数学图示，图示只辅助理解且不能代替公式与推导。
- 确认严谨性与条件检查：必须检查并明确写出会影响结论成立、方法选择或容易出错的定理条件；对题干中明显满足且不影响当前判断的常规条件，可以内部检查但不逐条展开。例如初等函数求极限时，不必机械列出其在去心邻域内可导。
- 确认定理与公式引用：解题时写清定理或公式名称、准确内容以及在本题中的具体使用方式即可，不附教材或章节来源；官方来源只用于维护考试大纲边界。
- 确认多题输入处理：一次只完整分析第一题；回答末尾识别并展示下一题的题干提示，询问用户是否继续分析第二题，不在同一回答中连续解完全部题目。
