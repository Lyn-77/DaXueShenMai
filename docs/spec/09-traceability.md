## 4. 冲突审计结论

当前规范已解决的主要冲突：

- “只提供解题”已细化为“具体题目解答、用户错解纠正、定理原理推导”，仍排除备考管理。
- “数学一全部内容”已澄清为覆盖数一、数二、数三的全部考研数学范围。
- “代码永远比推理可信”已校准为：检查输入、假设、实现和精度后，工具在复杂计算上优先；冲突时同时审查。
- “条件不足”已区分为输入残缺与题目故意考查不能推出。
- “跨 Agent 兼容”已限定为开放格式兼容，不承诺未测试客户端行为一致。

当前没有已知未裁决的产品需求冲突。
