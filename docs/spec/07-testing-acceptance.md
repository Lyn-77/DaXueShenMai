# L6：测试、验收与发布门槛

## 1. 测试目标

测试必须同时覆盖：

1. 数学正确性；
2. 触发准确性；
3. 输入澄清；
4. 教学与纠错流程；
5. 输出契约；
6. 可靠性和工具降级；
7. 能力边界；
8. 安装后的可发现性。

测试集通过不等于“所有数学题都绝对正确”，只表示已定义的发布门槛全部满足。

## 2. 测试执行边界

- TST-001 MUST：测试由当前 Codex 会话或安装后的 Agent 执行。
- TST-002 MUST NOT：设计 API Key、密钥配置或独立云端模型批量调用器。
- TST-003 MUST：测试定义可由人类或 Agent 阅读。
- TST-004 MUST：测试结果记录输入定位、观察结果、断言、证据和状态。

## 6. 用例结构

每个合成测试必须包含：

```yaml
id: 唯一编号
purpose: 测试目的
input_kind: screenshot-description | natural-language | latex | follow-up
prompt: 原创测试输入
context: 可选的上一轮上下文
should_trigger: true | false
required_behaviors:
  - 必须出现或执行的行为
forbidden_behaviors:
  - 禁止出现或执行的行为
blocking_assertions:
  - 阻断断言
quality_checks:
  - 质量检查
```

每个本地真题索引必须包含：

```yaml
id: 唯一编号
paper: math-1 | math-2 | math-3
year: 年份
question: 题号
page: PDF 页码
topic: 分层题型
answer_locator: 答案册页码或目录定位
expected_result: 可公开记录的短结果或哈希化/摘要结果
required_methods: 有则记录
verification: 独立复核方式
```

## 7. 阻断项

以下任一失败都使 v1 不通过：

- GATE-001：最终结论错误；
- GATE-002：关键推导错误；
- GATE-003：遗漏会改变结论的定理条件；
- GATE-004：编造题干、符号、条件、答案、来源或评分信息；
- GATE-005：模糊题干未澄清便继续求解；
- GATE-006：用户错解未定位首次错误或错误定位；
- GATE-007：超纲题强行解答；
- GATE-008：工具与推导冲突后仍直接给结论；
- GATE-009：使用或要求 API Key；
- GATE-010：多题输入未经确认连续解答；
- GATE-011：纯概念请求误触发完整解题流程；
- GATE-012：输出第二种明显无价值的方法。

所有阻断项必须 100% 通过。

## 8. 质量检查

质量检查包括：

- 题型定位是否有用；
- 线索映射是否完整；
- “为什么”是否讲清；
- 步骤粒度是否合适；
- 方法选择理由是否具体；
- 纠错迁移规则是否可执行；
- 语言与公式排版是否符合契约；
- 是否存在重复或空泛内容。

轻微措辞和样式问题可以记录为非阻断缺陷，但必须满足：

1. 不影响数学含义；
2. 不影响用户定位关键步骤；
3. 不违反明确的排版 MUST；
4. 在交付说明中公开记录。

## 9. 答案不一致处理

Skill 与答案册不一致时：

1. 不自动判 Skill 错；
2. 重新独立推导；
3. 使用不同方法或工具复核；
4. 检查题干 OCR 与答案题号是否对应；
5. 确认来源后记录结论；
6. 若答案册错误，只标记本地测试记录，不修改 PDF。

## 10. 回归顺序

每次修复后依次运行：

\[
\text{失败用例}
\rightarrow
\text{同类用例}
\rightarrow
\text{固定回归集}
\rightarrow
\text{必要时未见题}
\]

- TST-REG-001 MUST：失败用例未通过不得进入下一层。
- TST-REG-002 MUST：修复阻断错误后必须重跑所有固定回归。
- TST-REG-003 SHOULD：纯排版修复至少重跑输出契约类合成测试。

## 11. 结构与规范校验

实现完成后必须：

- 使用 skill-creator 提供的快速校验脚本检查 frontmatter 和目录；
- 在可用时运行 `skills-ref validate`；
- 检查 `name` 与目录一致；
- 检查 `SKILL.md` 长度符合渐进式披露建议；
- 检查所有相对引用存在且不形成深层引用链；
- 检查 Skill 不依赖仓库外绝对路径才能运行。

## 12. 发布判定

只有同时满足以下条件才可声明 v1 完成：

1. 结构校验通过；
2. 所有合成阻断断言通过；
3. 固定真题回归集通过；
4. 未见题集没有阻断错误；
5. 已知非阻断缺陷已记录；
6. README、许可证和安装说明与实际结构一致；
7. `docs/project/progress.md` 更新为完成；
8. 未自动安装、未自动推送远程仓库。
