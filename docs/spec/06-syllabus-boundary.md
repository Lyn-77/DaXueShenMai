# L5：考纲、知识边界与版本管理

## 1. 目标

本规范只解决两个问题：

1. 怎样判定 `dxsm-math` 应处理的考研数学范围；
2. 怎样在不猜测的前提下更新年度范围。

它不要求每次解题都联网，也不把完整考纲正文塞进 `SKILL.md`。

## 2. 范围定义

- SYL-001 MUST：能力范围取数学一、数学二、数学三官方考试内容的并集。
- SYL-002 MUST：范围至少包含高等数学、线性代数、概率论与数理统计中官方考纲要求的内容。
- SYL-003 MUST：不得把“以数学一为完整建设基线”误写为“只处理数学一”。
- SYL-004 MUST：自命题数学、数学分析、复变函数、抽象代数等不自动视为统考考研数学范围。

## 3. 官方来源优先级

从高到低：

1. 教育部年度全国硕士研究生招生工作管理规定；
2. 教育部教育考试院或中国教育考试网公开的考试大纲；
3. 高等教育出版社发布、作者明确为教育部考试中心或教育部教育考试院的正式大纲产品信息；
4. 用户合法提供的正式大纲正文。

- SYL-SRC-001 MUST：培训机构、自媒体、论坛、百科和转载只可用于发现线索。
- SYL-SRC-002 MUST NOT：使用二手页面单独确认“今年无变化”或“新增/删除某考点”。
- SYL-SRC-003 MUST：正式更新至少要有一个可核验官方来源和一份可检查正文或目录。

## 4. 版本元数据

每份已验证快照必须记录：

```yaml
exam_year: 目标考试年度
title: 正式大纲名称
author: 编写机构
publisher: 出版或发布机构
isbn: 有则记录，无则写 null
published_at: 发布或出版日期
verified_at: 本项目核验日期
source_url: 官方来源
content_available: true | false
previous_version: 上一已验证版本
change_status: changed | unchanged | unknown
notes: 核验说明
```

- SYL-META-001 MUST：未知字段写 `null` 或 `unknown`，不得猜填。
- SYL-META-002 MUST：`change_status: unchanged` 必须有正文对比或官方明确说明。
- SYL-META-003 MUST：核验日期与考试年度必须分开。

## 5. 年度更新流程

1. 检查教育部年度招生管理规定，确认统一命题科目和责任机构。
2. 检查中国教育考试网考试大纲栏目。
3. 检索高等教育出版社当年正式大纲产品信息。
4. 核对书名、作者、ISBN、发布日期和目录。
5. 取得合法可检查的正文或由用户提供正版内容。
6. 分别提取数学一、数学二、数学三的考试内容与要求。
7. 与上一已验证版本逐项对比。
8. 人工复核新增、删除、措辞变化和试卷结构变化。
9. 更新快照、变更记录和截止年份。
10. 运行范围相关边界测试。

- SYL-UPD-001 MUST：年度更新是维护动作，不在每次解题时执行。
- SYL-UPD-002 MUST：更新失败不得破坏上一已验证快照。
- SYL-UPD-003 MUST：更新完成前状态保持 `unknown`，不得提前宣称最新版。

## 6. 官方新版不可得时的回退

- SYL-FB-001 MUST：继续使用上一份已验证版本。
- SYL-FB-002 MUST：明确标注知识边界截止年份。
- SYL-FB-003 MUST：必要时请用户提供合法取得的最新版正文。
- SYL-FB-004 MUST NOT：根据培训机构整理稿静默替换官方快照。
- SYL-FB-005 MUST：若题目是否超纲因此无法确认，向用户说明版本限制，而不是强行拒绝或强行解答。

## 7. 解题时的范围判断

- SYL-RUN-001 MUST：普通考研数学题不重复展示考纲来源。
- SYL-RUN-002 MUST：只在范围判断成为问题时说明快照年份。
- SYL-RUN-003 MUST：明显超纲时简洁说明边界，不展开超纲知识教学。
- SYL-RUN-004 MUST：题目同时包含考纲内与考纲外部分时，说明无法按完整题处理；除非用户明确拆分出考纲内子问题。

## 8. Skill 内资源设计

实现阶段应在 `skills/dxsm-math/references/` 保存：

- 已验证范围的结构化摘要；
- 数一、数二、数三差异；
- 来源元数据；
- 截止年份；
- 更新流程入口。

不得打包：

- 未经许可的完整大纲扫描件；
- 培训机构整本资料；
- 本地真题与答案 PDF。
