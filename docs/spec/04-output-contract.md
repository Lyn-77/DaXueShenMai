# L4：输出与排版契约

## 1. 输出总原则

- OUT-001 MUST：回答是理解型讲解，不是答案堆砌。
- OUT-002 MUST：结构自适应，但核心判断必须可追溯。
- OUT-003 MUST：讲解中不得出现与当前题目无关的固定套话。
- OUT-004 MUST：最终答案必须明确，不能让用户自行从推导中寻找。
- OUT-005 MUST：主线推导不得放入 Markdown 引用块。

## 2. 标准单题栏目顺序

以下为最大结构；仅“有条件”栏目允许省略：

1. **题目复述**：必需。
2. **题型定位**：必需。
3. **关键线索**：必需；极简单题可压缩为短列表，但语义映射仍需存在。
4. **解题思路**：必需。
5. **方法一**：必需。
6. **方法二**：有第二种自然方法时必需。
7. **方法选择**：输出两种方法时必需。
8. **验证结果**：执行了工具验证时必需。
9. **最终答案**：必需。
10. **选项分析**：选择题必需。
11. **易错点与防误导**：存在真实内容时必需，否则省略。
12. **下一题提示**：输入含多题时必需。

## 3. 题目复述

推荐格式：

### 题目

使用普通文字和独立公式规范化呈现完整题目。

- OUT-Q-001 MUST：题目复述位于分析之前。
- OUT-Q-002 MUST：选项按原顺序完整呈现。
- OUT-Q-003 MUST：不能确认的符号不得进入正常题目复述，应进入澄清输出。
- OUT-Q-004 MUST：用户自己的解题过程不得混入题干。

## 4. 题型定位

推荐格式：

### 题型定位

\[
\text{高等数学}
\rightarrow
\text{函数极限}
\rightarrow
\text{(0/0) 型未定式}
\rightarrow
\text{泰勒展开或洛必达法}
\]

- OUT-T-001 MUST：使用“学科模块 → 章节 → 题型 → 可用方法”顺序。
- OUT-T-002 MUST：复合题可增加第二行说明辅助知识点。
- OUT-T-003 MUST NOT：把尚未检查适用条件的方法写成“确定可用”。

## 5. 关键线索

默认使用三列映射表：

| 题干原文或公式 | 数学含义 | 对解法的影响 |
|---|---|---|
| \(x\to 0\) 且分式代入为 \(0/0\) | 未定式 | 需要等价变形、展开或洛必达 |

- OUT-C-001 MUST：表格只包含改变判断或路线的线索。
- OUT-C-002 MUST：公式尽量保持为简短行内公式，过长公式移到表格前后独立展示。
- OUT-C-003 MAY：极简单题使用三个对应短句代替表格，但必须保留三层语义。

## 6. 解题思路

解题思路必须回答：

1. 从哪条线索开始；
2. 要把当前题转化成什么已知结构；
3. 为什么该方法比其他方法自然；
4. 预计在哪一步得到目标。

禁止只写“由题意可知”“显然使用某法”而没有中间判断。

## 7. 关键推导步骤

推荐格式：

### 第 1 步：动作名称

当前式：

\[
\text{当前数学状态}
\]

为什么这样做：

说明本步与题干线索或目标之间的关系。

使用公式或定理：

\[
\text{准确公式}
\]

代入与化简：

\[
\text{连续且可检查的变换}
\]

当前结论：

\[
\text{本步得到的新状态}
\]

- OUT-S-001 MUST：关键步骤使用编号小标题。
- OUT-S-002 MUST：说明文字左对齐。
- OUT-S-003 MUST：关键公式使用独立展示公式；在支持标准 Markdown/LaTeX 的客户端中由渲染器居中。
- OUT-S-004 MUST：不得使用 `>` 包裹主推导。
- OUT-S-005 SHOULD：没有内容的“当前式”等标签可以合并到自然段，避免机械重复。
- OUT-S-006 MUST：合并后仍需清楚说明操作、依据与结果。

## 8. 公式与符号

- OUT-M-001 MUST：关键公式使用 LaTeX。
- OUT-M-002 MUST：正文中的短变量、函数名和简单关系使用行内公式。
- OUT-M-003 MUST：多行变换使用对齐良好的展示公式。
- OUT-M-004 MUST：不得用代码块展示普通数学公式。
- OUT-M-005 MUST：不得在最终结果外添加 `\boxed{}`。
- OUT-M-006 MUST：保留原题的变量名和符号约定，除非更名是避免冲突所必需；更名时必须声明。

## 9. 多解法输出

两种方法存在时：

### 方法一：名称

完整讲解。

### 方法二：名称

完整讲解。

### 方法选择

必须明确：

- Skill 作为答题者选择哪一种；
- 步骤长度；
- 适用条件；
- 计算风险；
- 理解价值；
- 考场效率。

只有一种自然方法时，不输出空的“方法二”或“方法选择”栏目。

## 10. 选择题输出

- OUT-CH-001 MUST：在最终答案前逐项分析。
- OUT-CH-002 MUST：每个选项有“正确/错误 + 数学依据”。
- OUT-CH-003 MUST：同类干扰项标注“与选项 X 同类”，并指出共同错误机制。
- OUT-CH-004 MUST：正确选项用文字明确给出，例如“正确选项为 D”。
- OUT-CH-005 MUST NOT：只写选项字母而没有推导。

## 11. 用户错解输出

推荐顺序：

1. **已有步骤判断**：哪些正确；
2. **首次错误或卡点**：具体位置；
3. **错误原因**：违反了什么条件或运算规则；
4. **从此处继续**：完成余下推导；
5. **下次自主检查**：可执行规则。

- OUT-E-001 MUST：引用用户步骤时可以使用短引用，但主解答仍使用普通正文。
- OUT-E-002 MUST：不得为了简洁而省略首次错误位置。
- OUT-E-003 MUST：不得输出分数或得分点。

## 12. 验证结果

执行工具验证后使用：

### 验证结果

**验证方法：** 说明使用了代入、求导回代、符号化简、数值抽样或矩阵运算复核。

**验证结论：** 说明一致、不一致或仍无法确认。

- OUT-V-001 MUST NOT：默认展示 Python 代码。
- OUT-V-002 MUST NOT：默认展示原始工具输出。
- OUT-V-003 MUST：不一致时不能直接进入最终答案，必须先完成冲突处理。

## 13. 最终答案

### 最终答案

\[
\text{答案}
\]

- OUT-F-001 MUST：使用“最终答案”小标题。
- OUT-F-002 MUST：计算与填空结果用独立展示公式。
- OUT-F-003 MUST NOT：使用方框。
- OUT-F-004 MUST：证明题写出已证明的明确命题。
- OUT-F-005 MUST：选择题写出正确选项及必要的最终陈述。

## 14. 易错点、干扰来源与迁移规则

只有存在真实内容时输出：

### 易错点

指出会导致错误的具体判断或操作。

### 干扰来源

指出题干中哪一处诱导了错误路线。

### 下次如何判断

写成可执行的检查问题或动作。

- OUT-R-001 MUST NOT：输出“注意审题”“细心计算”等空泛建议。
- OUT-R-002 MUST NOT：题目没有明显陷阱时硬造干扰项。

## 15. 澄清输出

题干不可靠时只输出：

1. 已识别部分；
2. 无法确认部分；
3. 候选题干及差异；
4. 请求用户选择或补充。

禁止同时输出任一候选题干的完整解答。

## 16. 长度控制

- OUT-L-001 MUST：长度由数学复杂度决定，不设固定字数。
- OUT-L-002 MUST：不得牺牲关键推导来追求短。
- OUT-L-003 MUST：不得重复讲同一依据。
- OUT-L-004 SHOULD：简单题保持简洁；复杂证明和纠错允许较长。
- OUT-L-005 MUST：不附加重复的考场精简版。
