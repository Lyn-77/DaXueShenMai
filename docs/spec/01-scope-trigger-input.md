# L1：产品范围、触发与输入契约

## 1. 能力范围

- SCP-001 MUST：覆盖全部考研数学内容，包括高等数学、线性代数、概率论与数理统计。
- SCP-002 MUST：覆盖数学一、数学二、数学三涉及的题目，而不是只服务数学一考生。
- SCP-003 MUST：数学一仅作为“以最完整考研数学范围建设”的表达，不得被实现为只允许数学一。
- SCP-004 MUST：明显超出考研数学范围的题目不得求解，必须简洁说明 Skill 的能力边界。
- SCP-005 MUST：边界判断以最新“官方已验证”考纲快照为准，具体维护规则见 06 文档。

## 2. 正向触发

- TRG-001 MUST：用户发送一道考研数学题截图时触发。
- TRG-002 MUST：用户用自然语言描述考研数学题干时触发。
- TRG-003 MUST：用户发送 LaTeX 公式并附带题干描述时触发。
- TRG-004 MUST：用户只发送可识别为数学题的 LaTeX 公式或纯公式截图时触发。
- TRG-005 MUST：用户发送题目并附上自己的解题过程，要求判断、纠错或继续完成时触发。
- TRG-006 MUST：用户询问某个考研数学定理“怎么来的”“为什么成立”“为什么这样算”时触发。
- TRG-007 MUST：用户在多题场景中回复“分析第二题”等续题指令时，沿用上一轮题目上下文触发。
- TRG-008 SHOULD：描述中包含“求、证明、判断、计算、解、分析、哪里错、为什么这样做”等意图时提高触发置信度。

## 3. 负向触发

- TRG-020 MUST NOT：用户只询问纯定义、纯概念名称或只要求复述定理结论时触发。
- TRG-021 MUST NOT：明显属于复变函数、抽象代数等考研数学范围外的题目触发完整解题流程。
- TRG-022 MUST NOT：学习计划、复习安排、估分、课程推荐、错题管理等请求触发。
- TRG-023 MUST：负向场景若与定理推导意图共存，以推导意图为准。例如“拉格朗日中值定理的结论为什么成立”必须触发。

## 4. 输入类型

| 输入类型 | 必须执行 |
|---|---|
| 清晰截图 | 识别题干、规范化复述、继续求解 |
| 模糊截图 | 枚举候选题干或指出不可识别处，等待用户选择或补充 |
| LaTeX + 描述 | 保留符号体系，规范化排版 |
| 纯公式 | 将公式视作待分析题目；无语言线索时用中文 |
| 自然语言题干 | 转为规范数学表达并复述 |
| 题目 + 用户过程 | 进入判题与纠错流程 |
| 多道题 | 只处理第一题，保留下题上下文 |

## 5. 题干识别与确认

- INP-001 MUST：即使题干清晰，也要在讲解开头完整复述并规范化呈现题目。
- INP-002 MUST：复述不得改变定义域、参数范围、量词、符号、选项、图形条件或所求目标。
- INP-003 MUST：截图模糊、公式歧义、题干缺失或存在多个合理解释时，不得进入求解。
- INP-004 MUST：歧义时优先展示推测出的候选题干，让用户选择；无法形成可靠候选时要求用户手动输入或描述。
- INP-005 MUST：候选题干必须明确指出差异点，不能只问“请确认是否正确”。
- INP-006 MUST：用户确认后以确认版本作为唯一题干，不再混用其他候选。

## 6. 题干残缺与条件不足的区分

- INP-010 MUST：先判断“题目语义是否完整”，再判断“数学条件是否足以推出结论”。
- INP-011 MUST：OCR、截图或转述造成的残缺属于输入问题，必须追问。
- INP-012 MUST：题目完整但故意考查条件充分性的场景必须直接分析，不得擅自要求补条件。
- INP-013 MUST：当结论不能由条件推出时，必须用推导或反例说明。

示例：

\[
f'(0)=0
\]

不能单独推出 \(x=0\) 是极值点。可以用 \(f(x)=x^2\) 与 \(f(x)=x^3\) 给出相反情形。

## 7. 多题输入

- MUL-001 MUST：一次输入含多道题时，只完整分析第一题。
- MUL-002 MUST：回答末尾识别并展示下一题的简短题干提示，询问用户是否继续。
- MUL-003 MUST NOT：未经用户确认，在同一回答中继续解完第二题及之后题目。
- MUL-004 MUST：用户回复“分析第二题”后直接复用上一轮截图或题干，不要求重新上传。
- MUL-005 MUST：只有上一轮第二题本身无法可靠识别时才追问。

## 8. 输出语言选择

- LNG-001 MUST：中文题使用中文讲解。
- LNG-002 MUST：英文题使用英文讲解。
- LNG-003 MUST：纯公式输入没有自然语言线索时默认使用中文。
- LNG-004 MUST：保留题目原有数学符号体系，除非规范化是消除歧义所必需。
