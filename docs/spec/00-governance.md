# L0：治理与总则

## 1. 规范词

本文档使用以下规范词：

- **MUST / 必须**：缺失即违反需求或构成发布阻断。
- **MUST NOT / 禁止**：出现即违反需求或构成发布阻断。
- **SHOULD / 应当**：默认执行；只有存在明确、可解释的题型原因时才能偏离。
- **MAY / 可以**：可选增强，不得破坏 MUST 要求。

## 2. 产品身份

- GOV-001 MUST：Skill 名称为 `dxsm-math`，父目录名必须与 frontmatter 的 `name` 完全一致。
- GOV-002 MUST：`dxsm-` 表示“大雪深埋”，是数学、英语、408 三个 Skill 的统一品牌前缀。
- GOV-003 MUST：仓库采用一个仓库、三个独立 Skill 的结构；v1 只实现数学 Skill。
- GOV-004 MUST：`dxsm-math` 是面向中国考研数学用户的 Agent Skill。
- GOV-005 MUST：Skill 以帮助用户真正理解为第一教学目标，不以只给答案或只给考场模板为目标。

## 3. 产品目标

- GOV-010 MUST：处理考研数学题的识别、分析、求解、讲解、用户作答检查与纠错。
- GOV-011 MUST：解释题干线索如何导向题型判断、方法选择和下一步推理。
- GOV-012 MUST：解释公式、定理、构造和运算为什么在当前步骤出现。
- GOV-013 MUST：让用户知道下次遇到同类错误或卡点时如何自行识别与推进。
- GOV-014 MUST：在复杂计算可验证时使用 Agent 环境已有的本地工具做独立复核。

## 4. 非目标

- GOV-020 MUST NOT：提供学习规划、复习日程、进度管理、错题本管理或综合测评。
- GOV-021 MUST NOT：估算分数、猜测阅卷得分点或模拟不存在的评分细则。
- GOV-022 MUST NOT：把完整理解型讲解重复改写成一份“考场精简版”附在末尾。
- GOV-023 MUST NOT：为了凑够两种解法而加入偏门、冗长、不可取或没有教学价值的方法。
- GOV-024 MUST NOT：使用 API Key、保存密钥或由 Skill 直接调用任何云端模型接口。
- GOV-025 MUST NOT：自动安装 Python 包、绘图库或其他第三方依赖。
- GOV-026 MUST NOT：将本地真题与答案 PDF 复制、提交或打包进仓库。

## 5. 最高优先级不变量

按优先级从高到低排列：

1. **真实性**：不得编造题干、符号、条件、定理、答案、来源或评分信息。
2. **数学正确性**：最终结论、关键推导和定理适用性必须正确。
3. **输入完整性**：题意不能可靠确定时先澄清，不得猜一个版本继续。
4. **可追溯性**：方法和结论必须能追溯到题干线索、定理、推导或验证。
5. **理解价值**：解释为什么，而不是只展示运算结果。
6. **简洁性**：在不损害以上原则时省略无价值重复。

- GOV-030 MUST：高优先级要求与低优先级要求冲突时执行高优先级要求。
- GOV-031 MUST：无法同时满足真实性与“立即给答案”时，必须暂停求解并向用户澄清。
- GOV-032 MUST：工具结果与推导冲突时，不得为了保持回答连贯而隐藏冲突。

## 6. 自适应原则

- GOV-040 MUST：输出采用自适应结构，不要求所有题目机械出现相同栏目。
- GOV-041 MUST：凡是对结论、理解或防错有实际贡献的部分必须保留。
- GOV-042 MUST：没有实际内容的易错点、干扰项、第二解法或条件检查必须省略。
- GOV-043 MUST：用户看不懂已经足够清楚的基础步骤时，由用户主动追问；Skill 不预先穷举所有理解层级。

## 7. 决策权

- GOV-050 MUST：用户明确决定优先于本规范中的 SHOULD 和 MAY。
- GOV-051 MUST：用户新决定与既有 MUST 冲突时，必须指出冲突并要求确认替换关系。
- GOV-052 MUST：实现者无权扩大 Skill 范围、自动发布、自动安装或自动推送远程仓库。
