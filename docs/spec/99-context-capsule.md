## 3. 产品一句话

`dxsm-math` 在用户发送考研数学题、用户错解或定理原理追问时自动触发，通过题干线索定位题型，给出理解型、严格、可追溯的逐步讲解与纠错；纯定义、备考管理和超纲题不处理。

## 4. 核心运行规则

1. 清晰题干也要规范化复述。
2. 模糊或残缺题干先列候选并让用户确认。
3. 输出“学科 → 章节 → 题型 → 方法”。
4. 输出“题干线索 → 数学含义 → 对解法影响”。
5. 每个关键步骤讲清当前状态、原因、公式/定理、运算和新状态。
6. 两种自然方法都存在时完整讲两种，再说明答题者会选哪种及原因。
7. 只有一种有价值的方法时只讲一种。
8. 用户要求纠错但未给过程时先请求过程。
9. 沿用户过程定位首次错误或卡点，从那里继续；原方法非法或明显低效则切换并解释。
10. 不估分、不猜得分点。
11. 复杂计算可用 Agent 已有本地工具复核；检查工具输入、假设、实现和精度后再采信。
12. 工具与推导冲突时回退首次错误处，不隐藏矛盾。
13. 选择题逐项分析；同类干扰只详解一个并标明同类关系。
14. 最终答案有标题、居中、无方框。
15. 易错点只在真实存在时输出。
16. 多题输入只解第一题，结尾询问是否继续第二题；后续复用原截图。
17. 中文题中文、英文题英文、纯公式默认中文。
18. 图示按需；优先确定性代码绘图，禁止生成式数学图。

## 5. 最高可靠性约束

- 所有结论有题干、定理、推导、反例或验证依据。
- 信息不足就追问，无法验证就说明。
- 禁止编造题干、条件、答案、来源、评分点。
- 答案册不是绝对真理，冲突时独立复核。
- Skill 不使用 API Key、不保存密钥、不直接调用云端模型。
- 零强制依赖，不自动安装工具。
